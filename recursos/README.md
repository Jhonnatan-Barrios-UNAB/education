# Recursos alojados

Una carpeta por recurso, con su `index.html` y, si las tiene, sus imágenes en `img/`.
En `data/recursos.json`, el campo `enlace` apunta a la carpeta:

    "enlace": "recursos/hackea-al-estudiante/"

- Presentaciones y plantillas: usan el reproductor de `assets/deck/` (ver el README principal).
- Juegos, quizzes e infografías: páginas HTML completas e independientes.
